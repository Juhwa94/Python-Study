## 🎯 학습 목표
1. **Python 핵심 문법 및 객체지향(OOP) 구조 체득**: 효율적이고 재사용 가능한 코드 작성
2. **웹 데이터 수집 및 업무 자동화**: BeautifulSoup & Selenium을 활용한 동적/정적 데이터 수집 자동화
3. **머신러닝 기반 데이터 분석**: Scikit-learn을 활용한 데이터 전처리 및 회귀 분석 모델 구현
